🔍 GitHub Trust Score

AI-assisted authenticity consistency report for freelancer/developer portfolios

Analyzes all substantive public, non-fork repos (up to 20 deep-analyzed per run). Takes 20–60 seconds depending on profile size.
This tool produces a consistency/plausibility signal, not proof of fraud. Scores reflect patterns in public commit metadata only — private/client work is invisible to this analysis. Always use this alongside, not instead of, direct conversation with the candidate.
